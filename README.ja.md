# Base Diagram

フォルダの中のノートを、そのまま関係図として可視化するObsidianプラグインです。
土台はObsidian公式の[Bases](https://help.obsidian.md/bases)機能。
専用のファイル形式や、別のデータベースは一切使いません。ノート自体がデータで
あり、Base Diagramはそれを描画するだけです。

> あなたのノートは、常にただ一つの正しいデータ（Single Source of Truth）の
> ままです。Base Diagramはあなたのノートの内容をどこか別の場所に保存する
> ことはなく、frontmatterに既に書かれている情報を読み取るだけです。

## できること

対象フォルダを指定すると、Base Diagramは：

- 各ノートのfrontmatterを読み取り、**リンク形式のプロパティ**
  （例：`related: "[[別のノート]]"`）を関係として扱います
- 各ノートをテーブル風の箱として描画します（タイトル＋その他のプロパティ）
- リンクを書いた側（発信元）から、リンクされた側（参照先）へ矢印を引きます
- 箱をドラッグして自由に配置できます。位置はフォルダごとに保存されるので、
  次に図を開いたときもそのままです
- 箱から1クリックで、対応するノートを新しいタブで開けます

これは正式なカーディナリティ表記を持つ本格的なER図ツールではありません。
普段書いているデータを使って、1つのフォルダの中のノート同士がどう繋がって
いるかを、手軽に見えるようにするための軽量なツールです。

## 使用例

ノートの使い方はアイディア次第です。「このノートは、あのノートと関係がある」と
表せるものなら何でも図にできます。

- 小説のキャラクター相関図
- プロジェクト構造の整理（企画・調査・タスク・アイデア）
- 世界観設定（場所・勢力・出来事など）
- 軽めのデータ設計・システム構成のラフ

## 標準のグラフビューとの違い

Obsidian標準のグラフビューは、**Vault全体**を常に、レイアウトを制御でき
ない形で表示します。Base Diagramは、それとは違う目的の道具です：

| | グラフビュー | Base Diagram |
|---|---|---|
| 範囲 | Vault全体 | 1つのフォルダ |
| 配置 | 自動 | 手動、保存される |
| 表示内容 | リンクの存在 | 各ノートの中身 |
| 向いている用途 | 発見・眺める | 設計・構造化する |

## 使い方

1. フォルダ内のノートに、リンク形式のプロパティを追加します：

   ```yaml
   ---
   related:
     - "[[別のノート]]"
   type: table
   status: draft
   ---
   ```

2. そのフォルダ内のノートを開いた状態で、コマンドパレットから
   **Open relation diagram** を実行します。
3. 箱をドラッグして配置を整えます。配置は自動的に記憶されます。
4. 箱の中の **ページを開く**（言語設定によっては Open note）をクリックすると、
   対応するノートが開きます。
5. Obsidianを再起動した後は、ビュー右上の再読み込みボタンを押すだけで
   図を再表示できます（コマンドを実行し直す必要はありません）。

## 見やすい図にするためのコツ

- プロパティ名・値はどちらも短めに。長い値は箱に収まるよう自動的に省略
  されます（省略された値にマウスを乗せると全文が見られます）
- 「1ノート＝1つの概念」を意識する。1つのノートに詰め込みすぎず、
  関連する概念は別ノートに分けてリンクする方が、図としての意味が出ます
- リンクの向きは、自分の中で一貫したルールを決めておくと読みやすくなります
  （例：派生・詳細のノートから、元になったノートへ向けて書く、など）
- `related`（またはリンク用に使っているプロパティ）自体は、箱の中の
  プロパティ一覧には表示されません。矢印として表現されます

## オプション：色分け

`color` プロパティを追加すると、箱の背景色を変えられます：

```yaml
color: blue
```

対応する値：`red`／`blue`／`green`／`yellow`／`purple`。それ以外の値、
または未指定の場合は、既定の背景色のままになります。

## 動作要件

- Obsidian 1.8.7 以降（Bases機能・表示言語の検出に必要）

## インストール方法

### コミュニティプラグインから（おすすめ）

1. Obsidianの **設定 → コミュニティプラグイン** を開く
2. 制限モードがオンになっている場合は、**コミュニティプラグインを有効化** をクリック
3. **閲覧** をクリックし、**Base Diagram** で検索
4. **インストール** をクリックし、続けて **有効化** をクリック

### 手動インストール

1. [最新のリリース](../../releases/latest)から `main.js`・`manifest.json`・
   `styles.css` をダウンロード
2. `Vaultフォルダ/.obsidian/plugins/bases-relation-diagram/` を作成
3. 上記3ファイルをその中にコピー
4. Obsidianを再読み込みし、コミュニティプラグインから **Base Diagram** を有効化
## 現状の制約

- 配置は手動のみです。自動レイアウトのアルゴリズムは無いため、ノート数
  が多い図では関係線が交差したり、箱の裏を通ったりすることがあります
- 1つの図で表示できるのは1フォルダ分のみです
- 正式なカーディナリティ表記（1対多など）はありません。方向を示す矢印
  のみです
